## 3. Observations that bear on dependencies

- #99, #101, #102, #103, #104 were closed `completed` on 2026-10-08/09. The issue bodies require independent review; M1 did not read their comment threads for acceptance semantics. Treat them as present in source until the owner confirms the review record.
- #128 remains open with merged PRs #138, #139, #141 and open PR #140.
- Registry v2 semantics exist for eleven metric keys (`V2_SEMANTICS`). A metric outside them has no value-kind or range check.
- Daily aggregates keep `evidence_class` and lineage counts, not per-reading provenance. An assistant must not describe aggregate rows as individually verified readings.
